## 실행

일상 운영에는 `release` 폴더의 최신 `오늘도차근차근-*-x64-설치본.exe`를 권장합니다. 설치 없이 시험하려면 같은 버전의 `*-portable.exe`를 실행합니다. 두 방식 모두 개발 서버를 따로 켤 필요가 없고 동일한 문서 데이터 폴더를 사용합니다. 창의 닫기 버튼은 앱을 종료하지 않고 트레이로 숨기며, 트레이 메뉴의 `완전히 종료`가 실제 종료입니다.

개발 서버가 실행 중일 때 다음 주소를 사용합니다.

- 교사 화면: `http://127.0.0.1:5173/`
- 설정 화면: `http://127.0.0.1:5173/settings.html`
- 학생 화면: `http://127.0.0.1:5173/student.html`
- 사용 설명서: `http://127.0.0.1:5173/guide.html`
- 1인 1역: `http://127.0.0.1:5173/roles.html`
- 1인 1역 큰 글씨 출력: `http://127.0.0.1:5173/roles-print.html`

학생 화면을 교실 TV나 프로젝터에 띄워 두면 교사 화면과 실시간으로 동기화됩니다. 페이지를 한 번 클릭하면 효과음이 활성화됩니다.

## 처음 설정하는 순서

1. 설정 화면에서 학교급을 선택합니다. 초등 40분, 중등 45분, 고등 50분 수업 기준이 적용됩니다.
2. 교시 수(최대 8교시), 중간놀이와 점심 위치를 정하고 `시간 구조 저장`을 누릅니다.
3. 주간 시간표의 요일×교시 표에서 과목을 배정하고 `선택한 주에 저장` 또는 `다음 주로 저장`을 고릅니다. 학사관리 프로그램에서 받은 날짜·교시형 XLSX가 있으면 `학사 시간표 XLSX 가져오기`로 대신 채울 수 있습니다. 빈 교시는 표시되지 않습니다.
4. 교사 화면에서 명렬표 엑셀/CSV를 한 번 가져옵니다. 루틴 기록은 공용 데이터 폴더에 자동 저장됩니다.
5. 학생 화면을 새 창 또는 별도 디스플레이에 띄웁니다.
6. 1인 1역 화면에서 명렬표를 확인하고 자동 또는 수동으로 역할을 배정합니다.
7. 설정의 `급식·날씨와 안전 안내`에서 나이스 API 키를 입력하고 학교명을 검색합니다. 검색 결과에서 지역·학교급·주소를 확인해 고르면 교육청 코드와 학교 코드가 자동 입력됩니다. 기상청 격자 좌표와 API 키, 명렬표의 학생별 이메일·알레르기도 이곳에서 설정합니다.

학교급·기본 시간을 바꿔도 `개별 시간`으로 수정한 일정은 그대로 유지됩니다. 일과표를 다시 만들 때도 직접 추가한 일정은 보존되고, 일과표 생성기로 만든 일정만 교체됩니다.

주간 시간표는 월요일~일요일을 한 주로 계산해 월요일 날짜를 기준으로 각각 보관합니다. 이전·다음 주를 이동할 수 있고, 새 주에는 `지난주 시간표 가져오기`로 바로 복사할 수 있습니다.

## 알림과 수업 메모

- 사전 알림 기본값은 2분이며 전체 기본값과 일정별 값을 각각 바꿀 수 있습니다.
- 모든 팝업은 별도의 위쪽 간격 없이 브라우저 화면을 크게 사용합니다. 내용이 길면 글자를 축소하지 않고 팝업 내부에서 스크롤합니다.
- 교사·학생 알림 화면은 `현재 시각(HH:MM:SS)`, `일정 시작`, `시작까지 남은 시간`을 큰 세 칸 시계판으로 함께 표시합니다. 남은 시간은 초 단위로 줄어들며 시작 뒤에는 `지금 시작`·`진행 중`·`종료됨`으로 바뀝니다.
- 교사 화면 상단의 `타이머`를 누르면 1분부터 10분까지 바로 시작할 수 있습니다. 시작 즉시 교사·학생 화면에 `남은 시간 MM:SS`가 크게 열리고, 진행 막대와 종료 예정 시각이 보조로 표시됩니다. `작게 보기` 뒤에도 상단 카운트다운이 계속되며, 시간이 끝나면 큰 완료 화면과 효과음이 나옵니다. 새로고침해도 같은 종료 시각을 기준으로 계속 진행됩니다.
- 아침활동은 평일 08:40~08:55로 자동 추가됩니다. 안내에는 독서·레서·마타수학, 오늘 시간표 확인을 넣고 학생들이 잊기 쉬운 우유 마시기를 첫 문장과 🥛 표시로 강조합니다. 이어지는 08:55~09:00은 1교시 전 5분 쉬는 시간입니다.
- 청소 시간은 평일 13:40~13:50으로 자동 추가됩니다. 같은 시각의 청소 일정이 이미 있으면 중복으로 만들지 않으며, 교사·학생 알림을 브라우저 전체 화면의 대형 역할 게시판으로 열어 `1인1역_배정.csv`의 역할과 학생 이름을 크게 보여 줍니다. 크린토피아는 현재 요일 담당 한 팀만 알림에 표시하고, 다른 일반 역할은 모두 표시합니다.
- 점심이나 수업이 13:40 이후까지 이어져 청소와 겹치면 13:40~13:50 동안에는 청소 일정을 교사·학생 상단 카드에 우선 표시합니다. 시간 충돌 자체를 없애려면 점심 또는 앞 일정의 종료 시각을 13:40 이전으로 조정합니다.
- 하교 일정은 주간 시간표에 실제 입력된 과목을 요일별로 확인해, 마지막 과목이 5교시면 13:50, 6교시면 14:40으로 자동 배치됩니다. 같은 주에도 요일마다 하교 시각이 다를 수 있으며, 과목이 비어 있는 요일에는 자동 하교를 만들지 않습니다. 저장된 주간 시간표가 아직 없을 때만 전체 교시 수 설정을 기준으로 사용합니다. 하교는 사전 알림 없이 정시에만 알립니다.
- 시간표 편집 틀이 6교시로 설정되어 있어도 해당 요일의 6교시 과목 칸이 비어 있으면 그날은 5교시 하교로 처리합니다. 이전 버전의 단일 하교 일정은 페이지를 다시 열 때 요일별 하교 일정으로 자동 교체됩니다.
- 설정의 `일과 시간 기준 → 쉬는 시간 공통 안내`에서 일반 쉬는 시간·중간놀이·점심 문구를 한 번에 관리합니다. 저장 즉시 기존 일정과 앞으로 만드는 시간표에 적용되며, 일정별 추가 안내가 있으면 개별 문구가 우선합니다.
- 과목 기본 메시지, 일정별 추가 안내, 이전 수업에서 남긴 학생용 인계 메모가 학생 화면의 사전 알림에 함께 표시됩니다.
- 수업 완료 때 `학생에게 보일 메모`와 `교사만 볼 메모`를 구분해 남길 수 있습니다.
- 인계 메모는 쉬는 시간과 점심을 건너뛰고 다음 수업에 전달되며, 마지막 수업 뒤 메모는 다음 수업일 첫 수업으로 이어집니다.
- 학생 화면이 열려 있으면 학생 화면에서 알림과 효과음을 담당해 중복 알림을 막습니다.
- 교사 화면의 상단 현재·다음 일정 카드 또는 오늘의 루틴 카드를 누르면 알림 화면 형태의 큰 보기로 시간·안내·메모를 확인할 수 있습니다. 수동 큰 보기는 효과음을 재생하지 않습니다.
- 효과음은 기본으로 켜져 있고 기본 소리는 맑은 종입니다. 설정에서 맑은 종·나무 블록·반짝임 중 하나를 고르면 과목이나 일정의 종류와 관계없이 모든 알림에 공통 적용됩니다. 기본 출력은 이전보다 약 2배 크며, 각 음의 여운은 초기 길이의 3배이고 같은 길이의 묵음 뒤 총 3회 반복합니다. `일정 확인` 또는 `확인했어요`를 누르면 재생 중인 반복음이 즉시 멈춥니다. 음량은 50~150%로 조절할 수 있습니다.

## CSV와 명렬표

- `오늘의 기록`은 현재 시각이 일정 종료 시각을 지나면 기록 파일이 없어도 자동 완료로 표시합니다. 자동 완료는 화면 진행률에만 반영하고, `일정 종료`를 직접 누른 기록과 취소만 CSV에 저장합니다.
- 루틴 기록은 `문서\오늘도 차근차근\루틴기록.csv`에 자동 저장합니다. 교사 화면의 `사본 연결`은 다른 위치에도 별도 사본을 계속 기록하려는 경우에만 사용합니다.
- 개발 서버는 `문서\오늘도 차근차근\주간시간표_이력.csv`를 자동 생성합니다. 저장된 모든 주차의 시간 구조와 요일별 과목을 시작할 때 불러오며, 선택 주 또는 다음 주 시간표를 저장할 때마다 같은 파일을 자동 갱신합니다. `다음 주로 저장`은 현재 편집본을 다음 주에만 기록하고 현재 주 일정은 유지합니다.
- 학사관리 XLSX는 `교시` 행과 괄호 안 날짜가 있는 월~일 열을 찾습니다. `국어(담임)`처럼 끝에 붙은 교사명은 제거하고 휴일 문구와 빈 셀은 제외합니다. 파일 날짜로 주차를 정하며, 기존 과목은 자동 연결하고 일치하지 않는 이름은 미리보기에서 새 과목 추가·기존 과목 연결·제외 중 하나를 고릅니다. 파일은 외부 서버로 전송하지 않고 이 기기에서만 읽습니다.
- 명렬표는 `.xlsx`와 `.csv`를 지원하며 `번호`, `이름` 또는 `성명`, 선택 열인 `이메일`을 자동 인식합니다. `알레르기번호`에는 `1|2|6`처럼 번호를 넣을 수 있습니다. 저장한 이메일은 온라인 교실 로그인용 전체 백업에도 포함됩니다.
- 기존 명렬표에 이메일 열이 없다면 설정의 `학생 이메일·알레르기 확인`에서 학생을 선택해 이메일을 저장할 수 있습니다. 새 전체 백업을 만든 뒤 온라인 교실에서 `학생 이메일 명렬`을 선택하면 이메일이 있는 학생만 `Users` 시트에 등록됩니다. 이메일이 없는 학생은 자동 등록되지 않습니다.
- 교사 화면이나 1인 1역 화면에서 명렬표를 가져오면 서버가 `학생명렬표.csv` 사본을 공용 데이터 폴더에 저장합니다.
- 1인 1역의 역할 구성과 학생 배정은 `1인1역_배정.csv`에 자동 저장되며 새 브라우저 계정에서도 서버 주소로 열면 복원됩니다.
- `교실루틴_설정.json`에는 설정·과목·일정·기록·메모·시간표·명렬표·1인 1역 작업본이 자동 백업되어 다른 브라우저 계정에서도 같은 서버 주소로 복원됩니다.
- 사용자가 `사본 연결`로 지정한 추가 기록 파일의 권한은 브라우저가 관리하므로 재실행 뒤 다시 허용해야 할 수 있습니다.
- 파일에 접근하지 못할 때를 대비해 같은 작업본을 브라우저 저장소에도 유지합니다.

학생 개인정보가 포함된 파일은 학교 보안 지침에 맞는 위치에 보관하세요.

## 설치 위치와 데이터 위치

- 설치형 앱 기본 위치: `%LOCALAPPDATA%\Programs\class-routine`
- 웹 개발본 위치: 소스가 있는 `ClassRoutine` 폴더
- 모든 실행 방식의 공용 데이터 위치: `%USERPROFILE%\Documents\오늘도 차근차근`
- 개발·시험에서만 위치를 바꾸려면 서버 실행 전에 `CLASS_ROUTINE_DATA_DIR` 환경 변수를 지정합니다.

공용 데이터 폴더에는 다음 파일만 생성합니다.

- `교실루틴_설정.json`: 설정·과목·일정·메모·시간표 등 전체 작업본 자동 백업
- `주간시간표_이력.csv`: 주차별 일과 구조와 과목
- `루틴기록.csv`: 직접 종료하거나 취소한 일정 기록
- `학생명렬표.csv`: 이름 뽑기와 1인 1역에서 공유하는 명렬표 사본
- `1인1역_배정.csv`: 역할 정의, 배정 기간과 학생 배정 결과
- `데스크톱설정.json`: Windows 시작 시 자동 실행 등 설치 앱 전용 설정
- `외부연동설정.json`: 학교 코드, 기상 격자와 NEIS·기상청 API 키. 화면 API와 전체 작업본에는 비밀 키를 돌려주지 않음

기존 `ClassRoutine` 폴더에 실제 CSV가 있으면 서버가 처음 시작할 때 대상 파일이 없는 경우에만 공용 데이터 폴더로 복사합니다. 기존 파일은 삭제하거나 덮어쓰지 않습니다.

## GitHub와 개인정보

Git 저장소에는 프로그램 코드·문서·빈 CSV 양식만 보관합니다. 교실에서 생성되는 `학생명렬표.csv`, `주간시간표_이력.csv`, `1인1역_배정.csv`, 루틴 기록 CSV, `외부연동설정.json`과 서버 로그는 `.gitignore`로 제외됩니다. 브라우저 로컬 저장소에 있는 학급 설정과 메모도 Git 파일이 아니므로 업로드되지 않습니다.

## 기술 구성

- 화면 코어는 순수 HTML, CSS, JavaScript이며 Windows 포장에 Electron을 사용합니다.
- 설정·일정·기록은 브라우저 `localStorage`를 즉시 작업본으로 사용하고 `교실루틴_설정.json`에 자동 백업합니다.
- 같은 브라우저에서 열린 교사·설정·학생 화면은 `BroadcastChannel`로 즉시 동기화됩니다.
- 사용자가 별도로 고른 기록 사본과 명렬표 원본의 파일 핸들은 `IndexedDB`에 보관합니다.
- XLSX 명렬표는 브라우저에서 직접 읽으며 외부 서버로 전송하지 않습니다.
- 급식 조회에는 학교 코드와 날짜만, 날씨 조회에는 격자 좌표와 기준시각만 전송합니다. 학생 이름과 알레르기 정보는 외부 API로 보내지 않고 로컬에서만 대조합니다.

# 자리 바꾸기

`seating.html`에서 명렬표를 바로 불러와 자리를 배치합니다. 성별은 자리 배치에만 사용하는 선택 정보이며, 이름·번호가 든 원본 명렬표를 변경하지 않습니다. 분단과 좌석 수를 정하고 자동 배치한 뒤, 좌석을 두 번 눌러 학생 자리를 바꿀 수 있습니다. 확정한 회차는 데이터 폴더의 `자리배치_이력.csv`와 전체 백업 JSON에 저장됩니다.
