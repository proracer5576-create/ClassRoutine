03

DAY BUILDER

학교에 맞는 일과표 만들기

① 기본 시간과 공통 안내 저장

학교급을 선택한 뒤 수업·쉬는 시간과 기본 사전 알림을 확인합니다. 일반 쉬는 시간·중간놀이·점심 안내도 여기서 한 번에 작성합니다.

초등학교 40분중학교 45분고등학교 50분쉬는 시간 10분

② 하루 구조 만들기

1교시 시작 시각과 1~8교시 수를 선택합니다. 중간놀이는 2교시 뒤의 일반 쉬는 시간을, 점심은 선택한 교시 뒤의 일반 쉬는 시간을 대신합니다.

2교시→중간놀이
20·30분→3교시
1

시간 구조 미리보기에서 교시·쉬는 시간·점심의 시작과 종료를 확인합니다.

2

시간 구조 저장 후 월~금 각 교시의 과목을 선택합니다.

3

선택한 주에 저장 또는 다음 주로 저장을 고릅니다. 다음 주 저장 후에는 그 주로 이동해 결과를 보여 줍니다.

주차별로 따로 보관

월요일부터 일요일을 한 주로 계산하고 월요일 날짜를 기준 키로 사용합니다. 과거 주를 열어도 다른 주 시간표는 변경되지 않습니다.

다음 주 시간표를 미리 만들어도 이번 주가 바뀌나요?

바뀌지 않습니다. ‘다음 주로 저장’은 화면에서 수정한 표를 다음 주 월요일 키로 별도 저장하고 다음 주 자동 일정만 만듭니다. 이미 다음 주 시간표가 있으면 수업 개수를 보여 준 뒤 덮어쓸지 확인합니다.

일과표를 다시 만들면 무엇이 바뀌나요?

일과표 생성기로 만든 수업·쉬는 시간·중간놀이·점심 일정은 새 미리보기로 교체됩니다. ‘개별 일정 추가’로 직접 만든 아침활동, 청소, 하교 등의 일정은 그대로 남습니다.

04

ROUTINE EDITOR

일정을 세밀하게 수정하는 법

일정 유형

수업은 과목과 연결됩니다. 쉬는 시간은 기본 쉬는 시간 기준을 사용할 수 있습니다. 급식·조회·청소·하교는 기타가 알맞습니다.

시간 기준

학교급 설정을 계속 따르려면 ‘기본시간 사용’, 이 일정만 다르게 하려면 ‘개별 시간 사용’을 선택합니다.

자동 하교 일정

현재 주 시간표에서 요일별로 실제 입력된 마지막 과목을 확인합니다. 마지막 과목이 5교시면 13:50, 6교시면 14:40에 하교 일정이 자동으로 나타나므로 같은 주에도 요일마다 하교 시각이 다를 수 있습니다. 시간표 틀이 6교시여도 6교시 과목 칸이 비어 있으면 그날은 5교시 하교입니다. 과목이 없는 요일에는 자동 하교를 만들지 않으며 기본 2분 전 알림을 사용합니다.

사전 알림

전체 기본값, 일정별 개별 분, 알림 없음 중 선택합니다. 기본값은 시작 2분 전입니다.

학생 안내

그날 그 일정에서만 필요한 준비물, 자리 이동, 활동 방법 등을 적습니다. 과목 기본 안내와 함께 표시됩니다.

쉬는 시간 공통 안내

일과 시간 기준에서 일반 쉬는 시간·중간놀이·점심 문구를 각각 저장합니다. 개별 일정의 학생 안내가 비어 있을 때 공통 문구가 표시되며, 개별 문구를 작성하면 그 일정에서만 공통값을 대신합니다.

반복 요일

체크한 요일에만 일정이 표시됩니다. 요일별 시간표가 다르면 같은 교시 일정을 요일별로 나누어 만들 수 있습니다.

효과음과 색

효과음은 기본으로 켜져 있고 맑은 종이 선택됩니다. 알림 설정에서 다른 소리를 고르면 모든 과목과 일정에 같은 소리가 적용됩니다. 화면 색상은 일정별 구분을 유지합니다.

음량과 시험 재생

설정의 ‘알림과 표시’에서 맑은 종·나무 블록·반짝임 카드 중 하나를 누르면 공통 알림음으로 선택하면서 시험합니다. 교실 스피커에 맞게 50~150%로 조절한 뒤 알림 설정을 저장하세요.

과목 기본 안내

“수학 공책과 필기도구를 준비해요.”

+
일정별 추가 안내

“오늘은 모둠별 수학 놀이를 합니다.”

+
이전 수업 메모

“활동지 2쪽을 책상에 펼쳐 주세요.”

06

ONE STUDENT · ONE ROLE

명렬표로 1인 1역 정하기

PPT 기본 역할

칠판, 로켓배송, 환경부, 우유배송, 요일별 크린토피아, 보건도우미, 안내장 확인, 자료정리, 엔지니어, 창문·문틀이 기본으로 준비됩니다.

자동 배정

명렬표 학생 순서를 무작위로 섞어 한 학생에게 한 자리만 배정합니다. 학생 수보다 자리가 적거나 많으면 바로 알려 줍니다.

수동 배정

각 역할 카드의 자리에서 학생을 직접 선택합니다. 이미 다른 역할을 맡은 학생은 선택 목록에서 ‘배정됨’으로 표시됩니다.

역할 수정

역할 이름, 업무 안내, 필요한 학생 수, 분류와 색상을 바꿀 수 있고 우리 반만의 역할도 추가할 수 있습니다.

공유와 복원

서버 주소로 열면 명렬표는 `학생명렬표.csv`, 배정 결과는 `1인1역_배정.csv`에 자동 저장되어 다른 브라우저 계정에서도 이어집니다.

청소 시간 자동 안내

평일 13:40~13:50 청소 일정이 자동으로 준비됩니다. 기본 2분 전 알림과 시작 알림에 저장된 1인 1역 역할·학생 이름이 크게 표시되며, 같은 시각의 청소 일정은 중복 생성하지 않습니다.

다른 일정과 청소가 겹칠 때

13:40~13:50에는 청소를 교사·학생 상단 카드에 우선 표시합니다. 점심이 다시 나타나는 것이 불필요하면 일과 시간 기준에서 점심 종료가 13:40을 넘지 않도록 점심시간 길이를 조정하세요.

한 장 게시용 출력

‘큰 글씨 출력’을 누르면 모든 역할을 A4 가로 한 페이지에 꽉 차게 자동 배치합니다. 마지막 줄도 빈 칸 없이 넓혀 쓰며 미리보기에서 바로 인쇄·PDF로 저장할 수 있습니다.

한 학생은 한 가지 역할

중복 선택을 자동으로 막습니다. 결원이 생기면 빈 자리로 두거나 해당 역할의 필요한 학생 수를 조정하세요.

07

FILES & CONTINUITY

CSV 기록과 명렬표를 계속 활용하기

CSV

루틴 기록

  1. 교사 화면에서 ‘연결’을 누릅니다.
  2. 기존 기록 CSV를 선택하거나 새 파일명을 정합니다.
  3. 기존 내용과 브라우저 기록을 합친 후 완료·취소 때마다 자동 저장합니다.

주간 시간표 이력은 개발 서버가 프로그램 폴더의 `주간시간표_이력.csv`에 자동 보관합니다.

XLSX

우리 반 명렬표

  1. 명렬표의 ‘연결’을 누릅니다.
  2. XLSX 또는 CSV 파일을 선택합니다.
  3. ‘번호’와 ‘이름’ 또는 ‘성명’ 열을 찾아 이름 뽑기와 1인 1역에 사용합니다.

서버로 열면 `학생명렬표.csv` 사본이 프로그램 폴더에도 자동 저장됩니다.

개인정보

학생 명렬표와 기록 CSV는 학교가 정한 보안 위치에 보관하세요. 공용 컴퓨터를 다른 학급과 함께 쓸 때는 브라우저 사용자 계정을 분리하는 것이 좋습니다.

다시 실행했는데 파일 권한 확인이 필요한 이유

브라우저 보안 정책에 따라 파일 위치는 기억해도 쓰기 권한을 자동으로 다시 허용하지 않을 수 있습니다. 이때 교사 화면의 ‘연결’을 한 번 누르고 권한을 허용하면 자동 기록이 다시 이어집니다.

컴퓨터를 옮길 때 설정까지 가져가려면

설정 화면의 ‘전체 설정 백업’을 눌러 JSON 파일을 보관하세요. 새 컴퓨터에서 ‘백업 복원’을 선택하면 학교급, 과목, 일정, 기록과 인계 메모를 함께 가져올 수 있습니다.

08

DAILY RHYTHM

매일은 네 단계면 충분합니다

등교 전교사·학생 화면 열기

학생 화면을 한 번 눌러 소리를 활성화하고 오늘 일과를 확인합니다.

수업 전큰 알림 확인

과목 기본 안내, 일정별 안내, 이전 수업 메모가 학생 화면에 함께 나타납니다.

수업 후일정 종료와 인계 메모

시간이 지나면 화면 진행률은 자동 완료됩니다. 실제 종료 시각과 CSV 기록이 필요하면 ‘일정 종료’를 누르고 다음 수업 메모를 남깁니다.

하교 후기록과 다음 날 확인

오늘 일정 종료 현황과 CSV 연결 상태를 보고 교사 비공개 메모를 정리합니다.

실시간 동기화 설정·완료·메모·이름 뽑기 결과는 열린 화면 사이에 바로 전달됩니다. 학생 화면이 열려 있으면 학생 화면이 효과음과 큰 알림을 담당해 중복 알림을 막습니다.

일정 카드를 크게 보기

교사 화면에서 상단 현재·다음 카드나 오늘의 루틴 행을 누르면 시간과 안내가 알림 화면처럼 크게 열립니다. 이 수동 큰 보기는 알림음을 다시 재생하지 않습니다.

09

TROUBLESHOOTING

잘 안 될 때 확인할 것

효과음이 들리지 않거나 작아요.

설정의 ‘알림과 표시’에서 음량을 높이고 시험 버튼으로 교실 스피커 출력을 먼저 확인하세요. 브라우저는 사용자가 누르기 전 자동 재생을 막으므로 학생 화면을 한 번 클릭한 뒤 상단의 ‘소리 켜짐’을 확인합니다. 일정의 효과음이 ‘소리 없음’인지도 확인하세요.

오늘 일정이 보이지 않아요.

일정 수정에서 ‘일정 사용’과 오늘 요일이 선택됐는지 확인하세요. 일과표를 아직 적용하지 않았다면 설정 화면에서 미리보기를 만든 뒤 적용해야 합니다.

교사 화면과 학생 화면이 다르게 보여요.

두 화면 모두 `127.0.0.1:5173` 주소로 열었는지 확인하고 새로고침하세요. 서로 다른 브라우저나 다른 컴퓨터에서는 브라우저 저장소가 공유되지 않습니다.

기록 CSV가 자동 저장되지 않아요.

교사 화면의 파일 상태를 확인하세요. ‘권한 확인 필요’라면 ‘연결’을 눌러 같은 기록 CSV를 다시 선택하고 읽기·쓰기 권한을 허용합니다.

시간표 CSV는 어디에 저장되나요?

개발 서버가 HTML 파일과 같은 `ClassRoutine` 폴더의 `주간시간표_이력.csv`를 자동으로 읽고 갱신합니다. 설정 화면의 ‘폴더 CSV 다시 동기화’로 즉시 재확인할 수 있습니다.

시간을 바꿨는데 특정 일정만 그대로예요.

그 일정이 ‘개별 시간 사용’으로 설정되어 있기 때문입니다. 학교급 기본시간을 따르게 하려면 일정 수정에서 ‘기본시간 사용’으로 바꿉니다.

개발 서버 주소가 열리지 않아요.

`dev-server.mjs`가 실행 중인지 확인합니다. 서버가 실행되면 콘솔에 `ClassRoutine dev server: http://127.0.0.1:5173`가 표시됩니다.
