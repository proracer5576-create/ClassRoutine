03

DAY BUILDER

학교에 맞는 일과표 만들기

① 기본 시간과 공통 안내 저장

학교급을 선택한 뒤 수업·쉬는 시간과 기본 사전 알림을 확인합니다. 일반 쉬는 시간·중간놀이·점심 안내도 여기서 한 번에 작성합니다.

초등학교 40분중학교 45분고등학교 50분쉬는 시간 10분

② 하루 구조 만들기

1교시 시작 시각과 1~8교시 수를 선택합니다. 중간놀이는 2교시 뒤의 일반 쉬는 시간을, 점심은 선택한 교시 뒤의 일반 쉬는 시간을 대신합니다.

2교시→중간놀이
20·30분→3교시
1

시간 구조 미리보기에서 교시·쉬는 시간·점심의 시작과 종료를 확인합니다.

2

시간 구조 저장 후 월~금 각 교시의 과목을 선택합니다.

3

선택한 주에 저장 또는 다음 주로 저장을 고릅니다. 다음 주 저장 후에는 그 주로 이동해 결과를 보여 줍니다.

주차별로 따로 보관

월요일부터 일요일을 한 주로 계산하고 월요일 날짜를 기준 키로 사용합니다. 과거 주를 열어도 다른 주 시간표는 변경되지 않습니다.

학사관리 프로그램의 XLSX 시간표는 어떻게 가져오나요?

주간 시간표에서 ‘학사 시간표 XLSX 가져오기’를 누르고 날짜와 1~8교시가 들어 있는 XLSX를 선택합니다. 프로그램이 파일 날짜로 주차를 정하고, 과목 뒤 괄호의 교사명과 휴일 문구를 제외한 결과를 먼저 보여 줍니다. 자동으로 맞지 않은 과목만 새 과목으로 추가하거나 기존 과목에 연결한 뒤 저장하세요. 기존 시간표가 있는 주는 수업 수를 알려 주고 덮어쓰기를 다시 확인합니다. 파일 내용은 외부로 보내지 않습니다.

아침 일정은 어떻게 준비되나요?

평일 08:40~08:55에는 아침활동이, 08:55~09:00에는 1교시 전 쉬는 시간이 자동으로 준비됩니다. 아침활동 알림은 우유 마시기를 먼저 강조하고 독서·레서·마타수학과 오늘 시간표 확인을 함께 안내합니다.

다음 주 시간표를 미리 만들어도 이번 주가 바뀌나요?

바뀌지 않습니다. ‘다음 주로 저장’은 화면에서 수정한 표를 다음 주 월요일 키로 별도 저장하고 다음 주 자동 일정만 만듭니다. 이미 다음 주 시간표가 있으면 수업 개수를 보여 준 뒤 덮어쓸지 확인합니다.

일과표를 다시 만들면 무엇이 바뀌나요?

일과표 생성기로 만든 수업·쉬는 시간·중간놀이·점심 일정은 새 미리보기로 교체됩니다. ‘개별 일정 추가’로 직접 만든 아침활동, 청소, 하교 등의 일정은 그대로 남습니다.

04

ROUTINE EDITOR

일정을 세밀하게 수정하는 법

일정 유형

수업은 과목과 연결됩니다. 쉬는 시간은 기본 쉬는 시간 기준을 사용할 수 있습니다. 급식·조회·청소·하교는 기타가 알맞습니다.

시간 기준

학교급 설정을 계속 따르려면 ‘기본시간 사용’, 이 일정만 다르게 하려면 ‘개별 시간 사용’을 선택합니다.

자동 하교 일정

현재 주 시간표에서 요일별로 실제 입력된 마지막 과목을 확인합니다. 마지막 과목이 5교시면 13:50, 6교시면 14:40에 하교 일정이 자동으로 나타나므로 같은 주에도 요일마다 하교 시각이 다를 수 있습니다. 시간표 틀이 6교시여도 6교시 과목 칸이 비어 있으면 그날은 5교시 하교입니다. 과목이 없는 요일에는 자동 하교를 만들지 않으며 하교 알림은 사전 알림 없이 정시에만 표시합니다.

사전 알림

전체 기본값, 일정별 개별 분, 알림 없음 중 선택합니다. 기본값은 시작 2분 전입니다.

학생 안내

그날 그 일정에서만 필요한 준비물, 자리 이동, 활동 방법 등을 적습니다. 과목 기본 안내와 함께 표시됩니다.

쉬는 시간 공통 안내

일과 시간 기준에서 일반 쉬는 시간·중간놀이·점심 문구를 각각 저장합니다. 개별 일정의 학생 안내가 비어 있을 때 공통 문구가 표시되며, 개별 문구를 작성하면 그 일정에서만 공통값을 대신합니다.

반복 요일

체크한 요일에만 일정이 표시됩니다. 요일별 시간표가 다르면 같은 교시 일정을 요일별로 나누어 만들 수 있습니다.

효과음과 색

효과음은 기본으로 켜져 있고 맑은 종이 선택됩니다. 알림 설정에서 다른 소리를 고르면 모든 과목과 일정에 같은 소리가 적용됩니다. 화면 색상은 일정별 구분을 유지합니다.

음량과 시험 재생

설정의 ‘07 알림과 화면’에서 맑은 종·나무 블록·반짝임 카드 중 하나를 누르면 공통 알림음으로 선택하면서 시험합니다. 교실 스피커에 맞게 50~150%로 조절한 뒤 알림 설정을 저장하세요.

상단 빠른 타이머

교사 화면 상단의 타이머를 열고 1~10분 중 하나를 누르면 즉시 시작합니다. 교사·학생 화면에 남은 시간 `MM:SS`가 크게 열리고, 진행 막대와 종료 예정 시각도 함께 표시됩니다. `작게 보기`를 누르면 상단 숫자로 계속 확인할 수 있으며, 끝날 때 큰 완료 화면과 효과음이 다시 나옵니다. 새로고침해도 이어지고 교사는 타이머 메뉴나 큰 화면에서 중지할 수 있습니다.

ONE STUDENT · ONE ROLE

명렬표로 1인 1역 정하기

PPT 기본 역할

칠판, 로켓배송, 환경부, 우유배송, 요일별 크린토피아, 보건도우미, 안내장 확인, 자료정리, 엔지니어, 창문·문틀이 기본으로 준비됩니다. 전체표에는 월~금 크린토피아를 모두 보이지만, 청소 알림에는 오늘 요일 담당 한 팀만 표시됩니다. 청소 알림은 브라우저를 가득 채우며 역할명과 학생 이름을 교실용 큰 글씨로 보여 줍니다.

자동 배정

명렬표 학생 순서를 무작위로 섞어 한 학생에게 한 자리만 배정합니다. 학생 수보다 자리가 적거나 많으면 바로 알려 줍니다.

수동 배정

각 역할 카드의 자리에서 학생을 직접 선택합니다. 이미 다른 역할을 맡은 학생은 선택 목록에서 ‘배정됨’으로 표시됩니다.

역할 수정

역할 이름, 업무 안내, 필요한 학생 수, 분류와 색상을 바꿀 수 있고 우리 반만의 역할도 추가할 수 있습니다.

공유와 복원

서버 주소로 열면 명렬표와 배정 결과는 문서의 `오늘도 차근차근` 폴더에 자동 저장되어 다른 브라우저 계정에서도 이어집니다.

청소 시간 자동 안내

평일 13:40~13:50 청소 일정이 자동으로 준비됩니다. 기본 2분 전 알림과 시작 알림에 저장된 1인 1역 역할·학생 이름이 크게 표시되며, 같은 시각의 청소 일정은 중복 생성하지 않습니다.

다른 일정과 청소가 겹칠 때

13:40~13:50에는 청소를 교사·학생 상단 카드에 우선 표시합니다. 점심이 다시 나타나는 것이 불필요하면 일과 시간 기준에서 점심 종료가 13:40을 넘지 않도록 점심시간 길이를 조정하세요.

한 장 게시용 출력

‘큰 글씨 출력’을 누르면 모든 역할을 A4 가로 한 페이지에 꽉 차게 자동 배치합니다. 마지막 줄도 빈 칸 없이 넓혀 쓰며 미리보기에서 바로 인쇄·PDF로 저장할 수 있습니다.

한 학생은 한 가지 역할

중복 선택을 자동으로 막습니다. 결원이 생기면 빈 자리로 두거나 해당 역할의 필요한 학생 수를 조정하세요.

CSV

루틴 기록

  1. 서버 또는 설치 앱으로 교사 화면을 엽니다.
  2. 직접 누른 종료·취소 기록은 `루틴기록.csv`에 자동 저장됩니다.
  3. 다른 위치에도 기록하려면 ‘사본 연결’을 선택합니다.

시간표와 기록은 문서의 `오늘도 차근차근` 데이터 폴더에 함께 보관됩니다.

XLSX

우리 반 명렬표

  1. 명렬표의 ‘가져오기’를 누릅니다.
  2. XLSX 또는 CSV 파일을 선택합니다.
  3. ‘번호’와 ‘이름’ 또는 ‘성명’ 열을 찾아 이름 뽑기와 1인 1역에 사용합니다. 선택 열 ‘이메일’도 함께 읽습니다.

가져온 명렬표 사본은 `학생명렬표.csv`에 저장됩니다. 이메일 열이 없는 기존 명렬은 설정의 ‘학생 이메일·알레르기 확인’에서 학생별 이메일을 추가할 수 있습니다. 이후 만든 전체 백업에는 이메일도 포함됩니다.

개인정보

학생 이메일과 알레르기 정보가 들어 있는 명렬표 CSV·전체 백업 JSON은 학교가 정한 보안 위치에 보관하세요. 공용 컴퓨터를 다른 학급과 함께 쓸 때는 브라우저 사용자 계정을 분리하는 것이 좋습니다.

설치 앱에서 기존 자료가 안 보일 때

설정의 ‘데이터 연결 센터’에서 루틴·기록·주차·학생·역할 개수와 파일별 저장 상태를 먼저 확인하세요. ‘전체 작업본으로 복원’은 확인 후 문서의 전체 작업본을 현재 화면으로 복원합니다. 설치 앱의 ‘전체 백업 내려받기’와 ‘백업 JSON 가져오기’ 파일 창은 모두 이 데이터 폴더에서 시작합니다. 웹 버전은 브라우저 보안 정책에 따라 브라우저가 정한 다운로드·최근 선택 폴더를 사용합니다. 과거 수동 기록은 교사 화면의 ‘전체 기록 보기’에서 해당 날짜를 선택해야 보입니다.

데이터 폴더를 직접 확인하려면

설치 앱은 데이터 연결 센터의 ‘데이터 폴더 열기’를 누릅니다. 웹 개발본에서는 같은 버튼이 폴더 경로를 복사합니다. 모든 실제 자료는 문서\오늘도 차근차근에 있습니다.

다시 실행했는데 파일 권한 확인이 필요한 이유

공용 데이터 폴더는 별도 승인이 필요하지 않습니다. 사용자가 ‘사본 연결’로 고른 추가 파일만 브라우저 보안 정책에 따라 쓰기 권한을 다시 허용해야 할 수 있습니다.

컴퓨터를 옮길 때 설정까지 가져가려면

문서의 `오늘도 차근차근` 폴더 전체를 복사하거나 설정 화면의 ‘전체 데이터 백업’을 사용하세요. 백업에는 학교급, 과목, 일정, 기록, 메모, 시간표, 명렬표와 1인 1역이 포함됩니다.

급식과 날씨는 어떻게 연결하나요?

설정의 ‘급식·날씨와 안전 안내’에서 NEIS 인증키를 입력한 뒤 학교명을 검색합니다. 결과가 하나면 자동으로 선택되고, 여러 곳이면 교육청·학교급·주소를 확인해 학교를 고릅니다. 교육청 코드와 학교 코드는 자동 입력되므로 외울 필요가 없습니다. 기상청 격자 X·Y와 인증키도 저장한 뒤 ‘오늘 정보 불러오기’로 확인하세요. 비밀 키는 전체 백업이 아니라 문서 데이터 폴더의 `외부연동설정.json`에 별도로 보관됩니다.

학생 알레르기 정보는 외부로 전송되나요?

전송하지 않습니다. 급식 서비스에는 학교 코드와 날짜만 요청하고, 받아 온 메뉴의 알레르기 번호를 이 컴퓨터 안에서 명렬표와 대조합니다. 교사 화면에만 학생별 주의를 표시하며 학생 화면에는 개인 이름 없이 학급 공통 메뉴와 번호만 보입니다.

DAILY RHYTHM

매일은 네 단계면 충분합니다

등교 전교사·학생 화면 열기

학생 화면을 한 번 눌러 소리를 활성화하고 오늘 일과를 확인합니다.

수업 전큰 알림 확인

과목 기본 안내, 일정별 안내, 이전 수업 메모가 학생 화면에 함께 나타납니다.

수업 후일정 종료와 인계 메모

시간이 지나면 화면 진행률은 자동 완료됩니다. 실제 종료 시각과 CSV 기록이 필요하면 ‘일정 종료’를 누르고 다음 수업 메모를 남깁니다.

하교 후기록과 다음 날 확인

오늘 일정 종료 현황과 데이터 폴더 저장 상태를 보고 교사 비공개 메모를 정리합니다.

실시간 동기화 설정·완료·메모·이름 뽑기 결과는 열린 화면 사이에 바로 전달됩니다. 학생 화면이 열려 있으면 학생 화면이 효과음과 큰 알림을 담당해 중복 알림을 막습니다.

Windows 알림

설치 앱이 트레이에 실행 중이면 사전 알림 때가 아니라 일정 시작 정시에 Windows 알림이 나타나고 1분 뒤 자동으로 닫힙니다. 알림을 누르면 앱이 앞으로 나오고 해당 일정의 큰 화면이 열립니다. 트레이 메뉴에서 Windows 시작 자동 실행과 알림 시험을 확인할 수 있습니다.

오늘의 기록은 화면을 가리지 않습니다

교사 화면의 오늘의 기록 패널은 일정 목록 옆의 원래 위치에 머뭅니다. 페이지를 아래로 스크롤해도 따라오지 않아 급식·날씨·일정 자료를 덮지 않습니다.

급식도 큰 화면으로

랜딩의 급식과 날씨 카드는 같은 너비이며 작은 급식 카드에는 메뉴명만 간결하게 보입니다. 카드를 누르면 메뉴가 한 칸씩 큰 글씨로 표시되고 각 음식의 알레르기 번호와 식재료명도 함께 보입니다. 점심·급식 일정에도 당일 메뉴가 자동으로 연결되며, 교사 화면의 큰 급식판과 점심 알림에는 학생별 주의가 포함됩니다. 학생 화면에는 개인 이름이나 알레르기 프로필이 표시되지 않습니다.

일정 카드를 크게 보기

교사 화면에서 상단 현재·다음 카드나 오늘의 루틴 행을 누르면 시간과 안내가 알림 화면처럼 크게 열립니다. 팝업은 별도의 위쪽 간격 없이 브라우저 화면을 크게 사용합니다. 알림의 세 칸 시계판은 현재 시각, 일정 시작 시각, 초 단위 남은 시간을 동시에 보여 줍니다. 이 수동 큰 보기는 알림음을 다시 재생하지 않습니다.

TROUBLESHOOTING

잘 안 될 때 확인할 것

효과음이 들리지 않거나 작아요.

설정의 ‘07 알림과 화면’에서 음량을 높이고 시험 버튼으로 교실 스피커 출력을 먼저 확인하세요. 브라우저는 사용자가 누르기 전 자동 재생을 막으므로 학생 화면을 한 번 클릭한 뒤 상단의 ‘소리 켜짐’을 확인합니다.

오늘 일정이 보이지 않아요.

일정 수정에서 ‘일정 사용’과 오늘 요일이 선택됐는지 확인하세요. 일과표를 아직 적용하지 않았다면 설정 화면에서 미리보기를 만든 뒤 적용해야 합니다.

교사 화면과 학생 화면이 다르게 보여요.

두 화면 모두 `127.0.0.1:5173` 주소로 열었는지 확인하고 새로고침하세요. 같은 브라우저에서는 즉시 동기화되며, 다른 브라우저 계정은 공용 설정 백업을 페이지 시작 때 복원하므로 변경 뒤 새로고침이 필요할 수 있습니다.

기록 CSV가 자동 저장되지 않아요.

교사 화면의 파일 상태와 서버 실행 여부를 확인하세요. 정상 연결이면 `문서\오늘도 차근차근\루틴기록.csv`로 표시됩니다. ‘사본 연결’ 파일의 권한 문제는 해당 버튼을 눌러 다시 허용합니다.

자동 저장 파일은 어디에 있나요?

시간표·기록·명렬표·1인 1역과 설정 백업은 모두 `문서\오늘도 차근차근` 폴더에 있습니다. 설정 화면의 ‘파일 상태 확인’으로 저장 여부를 확인하고, ‘시간표 CSV 다시 읽기’로 시간표를 즉시 재확인할 수 있습니다.

시간을 바꿨는데 특정 일정만 그대로예요.

그 일정이 ‘개별 시간 사용’으로 설정되어 있기 때문입니다. 학교급 기본시간을 따르게 하려면 일정 수정에서 ‘기본시간 사용’으로 바꿉니다.

개발 서버 주소가 열리지 않아요.

`dev-server.mjs`가 실행 중인지 확인합니다. 서버가 실행되면 콘솔에 `ClassRoutine dev server: http://127.0.0.1:5173`가 표시됩니다.

화면이 순간적으로 다시 그려져요.

개발 서버는 HTML·CSS·JS 수정 시 페이지를 자동 새로고침하므로 개발 중 타이머나 큰 팝업이 순간 바뀔 수 있습니다. 설치본과 portable에는 이 실시간 새로고침을 넣지 않습니다.

창을 닫았는데 알림이 계속 나와요.

정상 동작입니다. 닫기 버튼은 앱을 트레이로 숨겨 일정을 계속 확인합니다. 작업표시줄 알림 영역의 ‘오늘도 차근차근’을 눌러 다시 열거나, 메뉴에서 ‘완전히 종료’를 누르세요.
